# DSA Pattern Practice

A structured collection of Data Structures and Algorithms practice problems, organised by topic and problem-solving pattern.

## Suggested Topics

- Arrays and Strings
- Hashing: maps and sets
- Two Pointers
- Sliding Window
- Sorting and Binary Search
- Recursion and Backtracking
- Linked Lists
- Stacks and Queues
- Trees and Binary Search Trees
- Heaps
- Graphs
- Greedy Algorithms
- Dynamic Programming

## Recommended Format for Each Solution

```text
Problem:
Platform / Link:
Pattern:
Approach:
Time Complexity:
Space Complexity:
Edge Cases:
```

Add only problems that are actually present in the repository. Keep one clearly named source file per problem and avoid duplicate solutions with unclear filenames.
